# Hosted documentation

[`whagent-docs.html`](whagent-docs.html) is the source of the hosted documentation site:

**https://claude.ai/artifact/Qy3QSk8i5sB376dQtPoF1a**

It is a single self-contained page with client-side routing — one screen per topic, a grouped sidebar, a filter (press <kbd>/</kbd>), an "on this page" index, prev/next navigation and a light/dark toggle. It carries the same material as the Markdown pages in [`docs/`](../README.md), which remain the canonical, version-controlled copy.

Open it locally by wrapping it in a minimal HTML skeleton, or edit and republish it to the same URL.
